# Project Angular

Projeto desenvolvido para a Aula 03 da disciplina de Frameworks Front-end.

A aplicação apresenta o **DevHub**, uma interface desenvolvida com Angular para apresentar algumas das principais tecnologias Front-end.

## Tecnologias

- Angular
- TypeScript
- HTML
- CSS

## Objetivo

Desenvolver uma aplicação utilizando Angular, aplicando conceitos de componentes e criação de interfaces Web.
